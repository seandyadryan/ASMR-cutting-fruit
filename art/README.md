# Artwork and audio

The hero, produce atlas and app icon were generated specifically for this project with the built-in image generation tool. Original full-resolution outputs are in `source/`. Prompts are in `prompts.md`. No external stock fruit, logos or game art are included.

`tools/prepare_assets.py` performs deterministic crop/resize/export operations and creates original synthetic ASMR textures using filtered noise, short transient bursts and a soft board resonance. Sounds are synthesized, not recordings of real produce.
